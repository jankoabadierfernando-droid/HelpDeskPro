# HelpDeskPro - Rand Internet Cafe Management System

HelpDeskPro is a full-stack IT support ticketing and cafeteria ordering web application designed for internet cafe operations. It features secure session handling, real-time station management, and instant staff notifications.

## Prerequisites & Dependencies
* Python 3.10+ installed on your system.
* MySQL database server (XAMPP / phpMyAdmin).
